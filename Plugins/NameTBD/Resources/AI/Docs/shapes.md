# Shapes and Shape Box

## Shapes
RectangleShape, EllipseShape, TriangleShape, StarShape, PolygonShape and CustomShape are vector widgets: crisp at any size, with a Fill and a Stroke. Fill and Stroke.Paint are FWidgetShapePaint: Type Color (one Color), LinearGradient (GradientStops, GradientAngle: 0 left to right, 90 top to bottom, -90 bottom to top), RadialGradient (GradientCenter, GradientRadius), Image (a texture or material brush; Image Mapping Along Outline runs a material along a stroke for edge glows) or Material (Material + MaterialParameters [{Name, Type Scalar|Color|Texture, Scalar, Color, Texture}] listed from the material; each shape draws its own instance, handed ShapeSize, OutlineLength, TrimStart, TrimEnd; Blueprint SetPaintMaterial / SetPaintScalarParameter / SetPaintColorParameter). Stroke: bEnabled, Width, Align Inside / Center / Outside, Join, Cap, DashLength, DashGap. Trim (Start, End, Offset) draws part of the outline - progress rings. Fit, ShapeScale, ShapeRotation, DesiredSize.

## Shapes hold a child
Every shape holds one widget drawn on top, like a Border: a label in a pill, a count in a badge, an icon in a circle. Content Area: Inscribed (largest rectangle inside the outline - default), Bounds, Inside Stroke. Size To Content (default on) grows the shape around its child. The child's slot (Shape Slot) has Padding and alignment. Hit Test Outline makes only the outline's inside clickable.

## Rectangle
CornerRounding (px), bFullyRounded (pill), bIndividualCorners + CornerRadii [top-left, top-right, bottom-right, bottom-left].

## Curve
CurveShape is a line of your own (a swoosh under a heading, an arrow pointing at a button, a divider, a wave, a sparkline): a CustomShape made for lines - open, stroked (Stroke.bEnabled true, Width 4, Round caps and joins), unfilled (bFill false), Self Hit Test Invisible. Path holds its points as box fractions (Contours[0].Vertices[i].Position, (0,0) top left, (1,1) bottom right; bClosed false). Smoothing: Smooth (Smooth Through Points - the curve flows through the points, Smoothness 0..2; a Disconnected vertex stays a sharp corner), Handles (each vertex's own InHandle / OutHandle), Straight (polyline, Corner Radius per vertex). Interpolation (for Smooth): CatmullRom (the default for new Curves; CatmullRomAlpha 0.5 never loops), Natural (smoothest, long even waves), Monotone (charts: never overshoots - use with PlotValues), BSpline (soft, points are a control cage), Balanced (older Curves). Ends: StartMarker / EndMarker (None, Arrow, OpenArrow, Dot, Diamond, Bar) and MarkerSize (px) - they ride the ends of the Trim Path. StartCapAngle / EndCapAngle (degrees, -80..80, Butt or Square cap): slanted ends - the same angle both ends gives parallel slants (a speed line, a slanted bar). Width: StartWidthScale / EndWidthScale (taper; 0 to a point), bUseWidthCurve + WidthCurve. bGradientAlongCurve (default true): a stroke gradient runs from the first point to the last. Draw it on: animate Trim End 0 -> 1 (Shape track TrimEnd). Ready-made curves: SetCurveFromTemplate (Line, Arc, SCurve, Wave, Zigzag, Spiral, Loop, Heartbeat, Swoosh, Bounce, Steps, Infinity) - or set Path directly. Curve Preset assets (WidgetCurvePresetAsset: Path, Smoothing, Smoothness, bApplyLook + the look): CurvePreset on a Curve applies and follows one. From Blueprint: SetPoints, AddPoint / AddPointAtLocalPosition (drawing), FitCurveToPoints (tidies points drawn live into a few smooth ones), ReverseCurve, SetInterpolation, SetCapAngles, PlotValues (a chart of numbers), GetPointAtFraction / GetPointAtDistance (position + angle - move an icon along it), FindFractionNearest, GetCurveLength. Example spec: {class: "CurveShape", name: "Underline", props: {DesiredSize: {X: 240, Y: 24}, EndWidthScale: 0}}, then set_widget {widget: "Underline", props: {"Stroke.Paint.Color": "@accent"}} or set_shape_paint on its stroke.

## Shape Box
ShapeBox bends its content into a shape (warps and clips it) - different from a shape, which draws a vector background under its content.
