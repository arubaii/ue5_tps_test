# Notifications (toasts, banners, feeds, hints, notification center)

## Notification Host
NotificationHost (palette NameTBD) is where notifications show; gameplay posts them to the player's UNotificationSubsystem and the host of the right channel draws them. Put one per HUD area in a Canvas slot: Preset Toasts (top right, cards), Banner (top center stretched, one big line at a time), Feed (top or bottom left, compact lines: loot, XP, kills), Hints (bottom center, one tip at a time), History (a scrolling notification center), Custom. Channels (gameplay tags Notification.Channel.Toast / Banner / Feed / Hint, or your own), HostPriority, MaxVisible (0 = the channel's). Layout: Growth Down / Up, StackLayout List / Deck (cards stacked, spread on hover), bNewestFirst, Spacing, ItemAlignment, ItemWidth, DeckPeek, DeckDepth. Motion: EnterTransition / ExitTransition (SlideFade, Slide, Fade, Pop, Rise), SlideFrom (Auto, Left, Right, Top, Bottom), SlideDistance, Motion (Smooth, Snappy, Bouncy, Gentle, Linear, Instant), EnterDuration, ExitDuration. Interaction: bInteractive (off for kill feeds: the mouse passes through), bPauseOnHover, ClickBehavior (Dismiss, FirstAction, EventOnly, None), bSwipeToDismiss, bShowOverflowCount ("+3"). Appearance: EntryWidgetClass (a UNotificationEntryWidget Widget Blueprint) or the built-in card with CardStyle (FNotificationCardStyle: Layout Toast / Banner / Compact, Width, Padding, BackgroundColor, BackgroundBlur (glass), CornerRadius, OutlineWidth, OutlineColor, ShadowColor, ShadowBlur, ShadowOffset, Accent Stripe / TopLine / Glow / None, AccentWidth, bUseSeverityColors with InfoColor / SuccessColor / WarningColor / ErrorColor / RewardColor / SocialColor or AccentColor, IconSize, bSeverityGlyph, TitleFont, TitleColor, BodyFont, BodyColor, CountFormat, bShowTimerBar, bShowCloseButton, bShowTimestamp, ButtonFont, ButtonColor, ButtonTextColor, ButtonCornerRadius, bShowKeyHints). bPreviewInDesigner + PreviewCount show samples in the designer.

## Posting
Blueprint Show Notification (Type, Title, Body) or Post Notification (FNotificationRequest: Type tag Notification.Type.Info / Success / Warning / Error / Reward / Loot / Elimination / Objective / Achievement / Social / System / Hint, Title and Body with {Count}, {Value} and TextArgs, Icon (Texture or SVG), Count, Value, Progress 0-1, StackKey (same key merges: "Wood x3"), Actions (ActionId, Label, Style Primary / Secondary / Destructive, GamepadKey, KeyboardKey, HoldTime, bDismisses), TimeoutActionId, overrides for Channel / Priority / Severity / Duration, Payload struct, ContextObject). Post Notification And Wait (async: On Posted, On Action, On Finished). Update Notification, Set Notification Progress, Dismiss Notification, Respond To Notification, Push / Pop Notification Suppression (Hold, Freeze, Drop - for cutscenes and menus). Server: Post Notification To Player / To All Players (needs a Notification Relay component on the Player Controller).

## Behavior
Per type (Project Settings > Plugins > Notifications > Types): Channel, Priority (Low, Normal, High, Critical), Severity, Duration (0 = until dismissed) + reading time, MaxQueueTime, StackPolicy (None, Merge, Replace, Ignore), Cooldown, CancelsTypes, bIgnoreSuppression, bKeepInHistory, sounds (Shown, Stacked, Action, Dismissed). Per channel: MaxVisible, MaxQueued, preemption, MakeRoom (feeds), Gap (banners). Player preferences (Set Notification Preferences): bDoNotDisturb, MutedTypes, DurationScale (accessibility, up to 10x), bKeepUntilDismissed, bScreenReaderAnnouncements, bReduceMotion, bPlaySounds. History: Get Notification History, Get Unread Count, Mark Notifications Read. Test in PIE with the console command NameTBD.Notify.Test. With no NotificationHost placed for a channel, a default one is put on screen by itself (Create Default Hosts in the settings); a placed host replaces it.

## Custom entry widget
A Widget Blueprint whose parent is NotificationEntryWidget; optional parts named TitleText, BodyText, IconImage, IconSVG, CountText, ProgressBar, TimerBar, ActionsPanel (with ActionWidgetClass, a NotificationActionWidget with ActionButton, LabelText, KeyText, HoldBar) are filled in automatically. Events On Notification Set / Updated (bStacked: pop the count) / Cleared.
