# Flow List

## What it is
FlowList lays its children along a path by their distance from the focus, in items: scroll lists, carousels, cover flows, picker wheels, dials, rings, stacks. Layout (Type Line / Arc / Wheel / Ring / Spline, Orientation, Spacing, Item Size), Effects by distance (Scale, Squash, Opacity, Rotation, Cross Offset, Spread, Tint, Edge Fade, Z Order - each Off, Falloff or Curve), Scrolling (snap, loop, drag, fling, spring, wheel, stick, navigation) and Transitions (enter / exit, intro stagger). StylePreset fills them all.

## Items
Add children (or set Entry Widget Class + Set List Items for a virtual list of thousands). Flow List Item Style (a UI component on an item) gives Selected / Unselected looks. Hover Magnify grows items under the pointer. Flow List Scroll Bar follows a list.

## With data
A Widget Data Binder List Binding fills a Flow List from a View Model array, keyed, with entrances, exits and slides.
