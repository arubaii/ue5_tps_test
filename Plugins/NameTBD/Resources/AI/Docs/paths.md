# Widget paths: skill trees, talent webs, flowcharts

## Widget Path Layer
WidgetPathLayer (palette NameTBD) draws lines between widgets of the same Widget Blueprint (its nodes). Place it in the same tree as the nodes, usually behind them and filling their area (Overlay or Canvas slot set to fill); it is Hit Test Invisible. Connections (FWidgetPathConnection: From, To - widget names -, Style (None: by Rules), bOverrideRouting + Routing, Progress 0..1 + ProgressStyle). In the designer: select two or more nodes and click Connect on the canvas toolbar to chain them (ordered left to right or top to bottom); Disconnect removes links among them. At runtime: Add Connection(From, To), Remove Connection, Clear Connections - for trees built from data.

## Routing
Routing (FWidgetPathRouting; a connection may override): Route Straight, Curve (Curvature), Elbow (Manhattan; ElbowPosition), Step, Diagonal (45-degree runs; ElbowPosition), Arc (Bend -1..1), Orbit (OrbitCenter widget or OrbitPoint; bOrbitLongWay - radial trees like Path of Exile), Waypoints (+ bSmoothWaypoints). Corner Round / Sharp / Chamfer + CornerRadius. Orientation Auto / Horizontal / Vertical. FromSide / ToSide Auto, Center, Left, Right, Top, Bottom. NodeShape Auto (reads ellipses, rounded rectangles, pills) / Box / Ellipse / Point. StartGap / EndGap (stop short of the node's edge). bSpreadPorts + PortSpacing (many lines on one side fan out).

## Styles, rules, states
Styles: named looks (FWidgetPathLook): Width, Paint Color / Gradient (GradientStops along the line, From = 0) / Image (ImageSource Texture or SVG, Image, SVG, ImageTileLength, ImageScrollSpeed - U along, V across), Cap, DashLength / DashGap / DashSpeed (marching), bOutline + OutlineWidth + OutlineColor, bGlow + GlowSize + GlowColor, Breathe + BreatheRate (pulsing glow), Flow None / Pulse / Dots / Arrows + FlowColor, FlowSpeed, FlowSpacing, FlowSize, FlowLength, StartMarker / EndMarker (Arrow, OpenArrow, Dot, Diamond, Bar) + MarkerSize, Opacity, DrawOrder. Rules (first match wins): FromState, ToState (None = any), bEitherWay, Highlighted / Hovered / Selected (Any, Yes, No) -> Style. Node states are names: DefaultNodeState "Locked", UnlockedState "Unlocked", AvailableState "Available" (bDeriveAvailable: a locked node linked to an unlocked one). States come from Set Node State / Set Node States, nodes implementing the Widget Path Node interface (GetWidgetPathNodeState, with bReadStatesFromNodes), or the Nodes list (also shown in the designer). Preset SkillTree (default), Constellation, Circuit, Flowchart, Metro, Organic, Radial fill Routing, Styles and Rules with Locked / Available / Unlocked / Highlighted styles.

## Highlight and animation
HoverHighlight None / Connections / RouteTo (route preview from the nearest unlocked node to the hovered one); bHighlightRouteToSelected with Set Selected Node (PreviewSelectedNode in the designer); bRoutesFollowDirection. Highlight Route(nodes), Highlight Node Connections, Clear Highlight. Transition DrawOn (new look runs along from the node reached first - the unlock animation) / Fade / Instant + TransitionDuration + TransitionMotion. Intro None / DrawOn / Fade + IntroDuration + IntroStagger (by depth from the roots); Play Intro. Queries: Find Route(target) (nodes from the nearest unlocked to the target - for costs), Get Connected Nodes, Get Nodes In State, Are Connected, Get Node State, Get Connection Path (route points, desktop space). Events On Node State Changed, On Hovered Node Changed.
