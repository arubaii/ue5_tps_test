# Menus, settings, graphs and prompts

## Settings menu in one call
create_settings_menu {name, tabs, title, style, colors, style_props, apply_policy} makes a Widget Blueprint (parent MenuSettingsScreen) holding a SettingsMenu named SettingsMenu that fills it, and a Menu Style data asset (DA_<Name>_Style) the menu is bound to - every colour, font, size, motion and sound of the menu comes from that asset, so "change its look" is set_asset on it. tabs: built-in pages by name (synonyms work: graphics / display -> Video, sound -> Audio, input / keybindings -> Controls, general -> Gameplay); any other name becomes a custom page in a Settings Schema it makes (DA_<Name>_Settings), filled with add_menu_settings. style presets: simple (dark, flat, blue accent - the default), light, glass (frosted over a blurred game), minimal (text on a scrim), console (large 10-foot type), high_contrast. colors keys: background, surface, row, row_hovered, row_focused, accent, accent_text, text, muted_text, disabled_text, divider, track, focus_outline, warning, negative, scrim. style_props: any FMenuStyle field (RowHeight, CornerRadius, RowSpacing, SectionSpacing, ValueWidth, DescriptionWidth, ContentMaxWidth, ScreenPadding, TitleFont / TabFont / LabelFont / ValueFont {Size, TypefaceFontName}, TabStyle Underline / Pills / Boxed, BoolDisplay Switch / Selector, SelectorMaxOptions, bShowPips, bShowDescriptionPanel, bShowSearch, bShowFooterHints, bShowModifiedDot, BackgroundBlur, BackgroundImage, Motion, PageTransitionSeconds, KeyCap, NavigateSound / ChangeSound / AcceptSound / BackSound / TabSound / ErrorSound {Sound}). apply_policy instant (console style: changes apply as made) or apply_button (PC style: Apply prompt, Back asks about unapplied changes). Display changes always ask to be kept, with a countdown.

To show it: a Menu Manager component Screens row (Widget Class = the Blueprint, Input Mode UI Only, Focus On Open Screen, Pauses Game) and Open Menu with that tag - or Create Widget + Add To Viewport. Back closes it through the Menu Manager.

## Built-in pages (ids for conditions and replacing)
- Gameplay: Gameplay.Language, Gameplay.FieldOfView, Gameplay.CameraShake, Gameplay.DoNotDisturb, Gameplay.NotificationSounds.
- Video: Video.WindowMode, Video.Resolution, Video.VSync, Video.FrameRateLimit, Video.Brightness, Video.HDR, Video.HDRBrightness; Video.Upscaler (Auto / DLSS / FSR / XeSS / TSR / TAA / FXAA / Off - only what this GPU and build support), Video.UpscalerMode, Video.ResolutionScale, Video.Sharpness, Video.DLSSRayReconstruction, Video.FrameGeneration, Video.LatencyReduction; Video.OverallQuality and the ten quality groups (Video.ShadowQuality...), Video.RenderDistance (r.ViewDistanceScale), Video.TextureFiltering, Video.HardwareRayTracing, Video.AutoDetect; Video.MotionBlur, DepthOfField, Bloom, LensFlares, ChromaticAberration, FilmGrain; Video.PerformanceOverlay (Off / FPS / FrameTimes / Detailed), Video.Benchmark; Video.Info.* (GPU, driver, API, CPU, memory).
- Audio: Audio.MasterVolume, MusicVolume, EffectsVolume, DialogueVolume, UIVolume, VoiceVolume (sound classes assigned in Project Settings > Plugins > Menus > Audio Channels; Master always works), Audio.BackgroundVolume, Audio.Quality.
- Controls: Controls.MouseSensitivity, MouseInvertY, GamepadSensitivityX / Y, GamepadInvertY, GamepadDeadZone, Vibration, VibrationStrength, AimAssist, ButtonPrompts; key binding sections (Enhanced Input player mappable keys) and Controls.ResetKeyBindings.
- Accessibility: Accessibility.ColorBlindMode, ColorBlindStrength, UIScale, HighContrast, ReduceMotion, ReduceFlashing, Subtitles, SubtitleSize, SubtitleBackground, SpeakerNames, MenuNarration, ReadNotifications, NotificationDuration, KeepNotifications, ToggleInsteadOfHold.

## Adding settings
add_menu_settings {schema, page, section, settings, menu}: page "Video" adds to the built-in page; any other makes a page. A setting: {id, type bool | number | choice | action | info | key_binding, name, description, default, min, max, step, format number | percent (0..1 shown as %) | percent_value | multiplier, units, min_text ("Off"), options ["Low", "High"] or [{value, label, description}], display auto | selector | dropdown | buttons, action event | auto_detect_graphics | reset_page | reset_all | reset_key_bindings | run_benchmark, button, confirm, target, scope user | machine, apply default | immediately | on_apply, requires_restart, requires_confirmation, shown_when / enabled_when [{setting, compare, value}], keywords, props}. Targets: {type: "cvar", name: "r.ViewDistanceScale", scale, invert, also_set} - any console variable; {type: "game_user_setting", field: VSync | WindowMode | Resolution | FrameRateLimit | OverallQuality | ShadowQuality | ... | HDROutput}; {type: "built_in", field: DisplayGamma | UIScale | ColorBlindMode | ColorBlindStrength | Subtitles | BackgroundVolume | Vibration | VibrationStrength | ReduceMotion | HighContrast | MenuNarration | ControllerButtonStyle | FieldOfView}; {type: "sound", channel: "Music"}; {type: "notification", field: DurationScale | KeepUntilDismissed | ScreenReader | ReduceMotion | PlaySounds | DoNotDisturb}; {type: "graphics", field: Upscaler | UpscalerMode | FrameGeneration | LatencyReduction | Sharpness | ResolutionScale}; {type: "language"}; {type: "saved"} (no target: the game reads it with Get Setting Number / Bool / Value, a Setting Binder component, or the Scale By Setting input modifier). Conditions may test system values: @ActiveUpscaler, @ActiveFrameGeneration, @GPUVendor (NVIDIA / AMD / Intel), @InputDevice (KeyboardMouse / Gamepad / Touch), @Platform, @RayTracingSupported.

Example "add a Render Distance slider and an FOV slider to Video": add_menu_settings {page: "Video", section: "View", settings: [{id: "Video.MyRenderDistance", type: "number", name: "Render Distance", default: 1, min: 0.5, max: 2, step: 0.1, format: "multiplier", target: {type: "cvar", name: "r.ViewDistanceScale"}}], menu: "<the menu>"}.

## Pieces for your own menus
SettingControl (palette NameTBD): one setting's row in the built-in look (SettingId, StyleAsset). MenuSettingRowWidget: a Widget Blueprint parent for custom rows (parts LabelText, ValueText, DescriptionText; events On Setting Assigned / On Setting Refreshed; Set Value, Step, Reset To Default, Run Action) - per kind in a style's RowWidgetClasses. MenuKeyPrompt: "[A] Accept" that follows the device and rebinding (InputAction or KeyboardKey / GamepadKey, Label, KeyCap). StatGraph: live graph (Preset CompactFPS / FPS / FrameTimes / Detailed / Memory / Network, or Series of sources FrameRate, FrameTime, ThreadTime, Memory, ConsoleVariable, Ping, Manual). Show Menu Dialog (async Blueprint node): "Quit to desktop?" with buttons, Back = cancel, optional timeout.
