# Constraints and pointer effects

## Constraints (UI Component)
UWidgetConstraintComponent ("Constraints") on any widget: Constraints (a list, applied in order), Strength, bSolveInDesigner, bShowInDesigner (magenta lines to targets and paths). Never writes the Render Transform: the widget is drawn and hit-tested with an extra transform over it, so animations keep working underneath. Every constraint: ConstraintName, bEnabled, Strength 0..1, Activation Always / WhileHovered / WhilePressed / NearPointer (ActivationRadius), ActivationFade, bSmooth + Smoothing (spring VisualDuration, Bounce - lag and overshoot). Target (FWidgetConstraintTarget): Kind Widget (Widget name, Anchor 0..1) / Pointer (WhenPointerAway Release or HoldLast) / Parent (Anchor) / Point (offset from rest). Types: Copy Position (SourceSpace Screen or Local, bCopyX/Y, CopyAmount = how far toward the target, Offset, bKeepStartingOffset, bLimit Min/Max from rest), Copy Rotation (Local copies the target's angle; CopyAmount -1 for meshing gears; AngleOffset; limits), Copy Scale, Copy Transform (pin to a widget: Offset in its units, AngleOffset, bKeepStartingOffset), Distance (Within / Outside / Exact, Distance), Follow Path (PathSource ShapeOutline - e.g. an Ellipse ring -, WidgetBox (EdgeShape), Circle (Radius, StartAngle round Target), WidgetPathConnection (PathWidget = layer, ConnectionFrom/To); PathOffset; Mode Distance (PathPosition fraction or bPositionInPixels, Speed per second, bLoop) or ClosestToTarget (knob following the pointer round a dial); bOrient + OrientOffset), Look At (ForwardAngle, AngleOffset, bKeepUpright, limits), Stay Inside (Area Parent or AreaWidget, AreaShape Auto/Box/Ellipse, Margin, bKeepWholeWidgetInside, Elasticity), Remap (Measure OffsetX/OffsetY/Distance/Direction/TargetAngle/TargetScale/TargetOpacity, FromRange -> Drive OffsetX/OffsetY/Angle/Scale/ScaleX/ScaleY/Opacity over ToRange, bClamp, curve), Pointer Parallax (Depth, Tilt, Area Screen or AreaWidget).

## Constraint recipes
Ball round a ring: Follow Path, ShapeOutline of an Ellipse, Speed 0.25. Eyes following the cursor: on each pupil Copy Position -> Pointer, CopyAmount 0.15, bSmooth; then Stay Inside the eye white (Ellipse). Magnetic button: Copy Position -> Pointer, CopyAmount 0.3, Activation NearPointer, bLimit +-12, bSmooth Bounce 0.3. Dial knob: Follow Path Circle, ClosestToTarget -> Pointer (HoldLast), Activation WhilePressed. Trail: each dot Copy Position -> the previous dot, bSmooth. Dock magnify: Remap Distance (from edges) 0..150 -> Scale 1.5..1 toward the Pointer. Blueprint: Get Widget Constraints(widget), Find Constraint, Add Constraint(class), Set Constraint Value(name, channel Strength/PathPosition/OffsetX/OffsetY/AngleOffset/Distance), Set Target Widget, Reset Constraint Motion. Widget Animation track "Constraint" (category Interaction) animates a channel.

## Pointer Effects (UI Component)
UPointerEffectsComponent ("Pointer Effects") on any widget. Preset TiltCard (default), HolographicCard, ShimmerButton, MagneticButton, SpotlightBorder, Ripple, Lift, Custom. Intensity. Tilt (bEnabled, MaxAngle, Direction PressAway / RiseToward, Perspective, HoverScale, Spring). Magnet (Pull, MaxOffset, Range, Spring). Press (PressScale, Spring). Lights (list of FPointerLight: Kind Spotlight / Sheen (shimmer band: SheenAngle, SheenWidth) / BorderGlow (BorderWidth) / Holographic; Show WhileHovered / NearPointer / Always; Color alpha = strength; Radius). Ripple (Color, Duration). bMatchWidgetCorners or CornerRadius. ProximityRange, HoverFade, bReactToFocus (gamepad focus = hover), Set Virtual Pointer (stick). Outputs: bDriveMaterials (material parameters Pointer = (U, V, hover, pressed), PointerHover, PointerVelocity = (x, y, speed, proximity) on Image / Border / shape materials, bIncludeChildren), bDriveShapeGradients (radial gradient center follows the pointer), AnimationPointerValue / AnimationHoverValue (Widget Animation values), MachinePointerInput / MachineHoverInput / MachineProximityInput (state machine inputs). Event On Pointer Effects Updated; Get Pointer State. bPreviewInDesigner + DesignerPointer. Widget Animation track "Pointer Effects" (Intensity, TiltAngle, MagnetPull, LightStrength). Value input "Pointer Distance and Motion" (Distance, Proximity, Direction, Speed, VelocityX/Y) on any value track.
