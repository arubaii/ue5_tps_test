# Constraints and pointer effects

## Constraints (UI Component)
UWidgetConstraintComponent ("Constraints") on any widget: Constraints (a list, applied in order), Strength, bSolveInDesigner, bShowInDesigner (magenta lines to targets and paths). Never writes the Render Transform: the widget is drawn and hit-tested with an extra transform over it, so animations keep working underneath. Every constraint: ConstraintName, bEnabled, Strength 0..1, Activation Always / WhileHovered / WhilePressed / NearPointer (ActivationRadius), ActivationFade, WhileAnimated ActOver (default) / LetGo (fades out while a Widget Animation moves the widget) / FollowKeys (the keyed place becomes the target, reached with the constraint's smoothing and limits - keyed pupil looks), bSmooth + Smoothing (spring VisualDuration, Bounce - lag and overshoot). Motion paths in the designer show constrained widgets where their constraints put them (and Constraint tracks' paths). Target (FWidgetConstraintTarget): Kind Widget (Widget name, Anchor 0..1) / Pointer (WhenPointerAway Release or HoldLast) / Parent (Anchor) / Point (offset from rest). Types: Copy Position (SourceSpace Screen or Local, bCopyX/Y, CopyAmount = how far toward the target, Offset, bKeepStartingOffset, bLimit Min/Max from rest), Copy Rotation (Local copies the target's angle; CopyAmount -1 for meshing gears; AngleOffset; limits), Copy Scale, Copy Transform (pin to a widget: Offset in its units, AngleOffset, bKeepStartingOffset), Distance (Within / Outside / Exact, Distance), Follow Path (PathSource ShapeOutline - e.g. an Ellipse ring -, WidgetBox (EdgeShape), Circle (Radius, StartAngle round Target), WidgetPathConnection (PathWidget = layer, ConnectionFrom/To); PathOffset; Mode Distance (PathPosition fraction or bPositionInPixels, Speed per second, bLoop) or ClosestToTarget (knob following the pointer round a dial); bOrient + OrientOffset), Look At (ForwardAngle, AngleOffset, bKeepUpright, limits), Stay Inside (Area Parent or AreaWidget, AreaShape Auto/Box/Ellipse, Margin, bKeepWholeWidgetInside, Elasticity), Remap (Measure OffsetX/OffsetY/Distance/Direction/TargetAngle/TargetScale/TargetOpacity, FromRange -> Drive OffsetX/OffsetY/Angle/Scale/ScaleX/ScaleY/Opacity over ToRange, bClamp, curve), Pointer Parallax (Depth, Tilt, Area Screen or AreaWidget).

## Constraint recipes
Ball round a ring: Follow Path, ShapeOutline of an Ellipse, Speed 0.25. Eyes following the cursor: on each pupil Copy Position -> Pointer, CopyAmount 0.15, bSmooth, WhileAnimated FollowKeys; then Stay Inside the eye white (Ellipse) - keyed looks on the pupil's Transform track then spring there inside the eye. Magnetic button: Copy Position -> Pointer, CopyAmount 0.3, Activation NearPointer, bLimit +-12, bSmooth Bounce 0.3. Dial knob: Follow Path Circle, ClosestToTarget -> Pointer (HoldLast), Activation WhilePressed. Trail: each dot Copy Position -> the previous dot, bSmooth. Dock magnify: Remap Distance (from edges) 0..150 -> Scale 1.5..1 toward the Pointer. Blueprint: Get Widget Constraints(widget), Find Constraint (by Name, or the kind's name e.g. "Follow Path"), Get Constraint Names, Add Constraint(class), Set Constraint Value(name, channel Strength/PathPosition/OffsetX/OffsetY/AngleOffset/Distance), Set Target Widget, Reset Constraint Motion. Widget Animation track "Constraint" (category Interaction) animates a channel.

## Pointer Effects (UI Component)
UPointerEffectsComponent ("Pointer Effects") on any widget. Preset (quick starts named by trigger) TiltCard "Tilt Card Hover" (default), HolographicCard "Holographic Card Hover", ShimmerButton "Shimmer Hover", MagneticButton "Magnetic Hover", Ripple "Ripple Click", Custom. PresetAsset (UPointerEffectsPresetAsset "Pointer Effects Preset": Tilt, Magnet, Press, Lights, Ripple, Overlays; Save As Preset, Apply Preset Asset, Copy To Preset Asset). Intensity. ActiveWhen (condition over everything). Tilt (bEnabled, ShowWhen, MaxAngle, Direction PressAway / RiseToward, Perspective, HoverScale, Spring). Magnet (ShowWhen, Pull, MaxOffset, Range, Spring). Press (ShowWhen, PressScale, Spring). Lights (list of FPointerLight: Kind Spotlight / Sheen (SheenAngle, SheenWidth) / BorderGlow (BorderWidth) / Holographic; Show WhileHovered / NearPointer / Always; ShowWhen; Color alpha = strength; Radius). Ripple (ShowWhen, Color, Duration). Overlays (FPointerOverlay: ShowWhen, Image = texture / material / SVG (FWidgetEffectImage with MaterialParameters), Placement Fill / FollowPointer (Size, cut to the widget) / FollowPointerUncut, Tint, bBehindContent) - materials get Pointer (U, V, hover, pressed), PointerHover, PointerVelocity (x, y, speed, proximity), PointerProximity, PointerPressed, EffectStrength, WidgetSize every frame. ShowWhen (FPointerEffectCondition): Trigger Default / Always / WhileHovered / NearPointer / WhilePressed / WhileFocused / ConditionOnly + Condition name (+ bInvertCondition); conditions come from Set Effect Condition(name, bool) / Clear Effect Condition, the widget or its User Widget implementing the Pointer Effects Condition interface (GetPointerEffectCondition(name, out met) -> answers), or built-ins On / Off (Context Menu Button toggle) and Usable / Disabled. bMatchWidgetCorners or CornerRadius. ProximityRange, HoverFade, bReactToFocus (keyboard/gamepad navigation focus = hover; a click's focus doesn't), bReactWhileDisabled (off: disabled widgets lie still), Set Virtual Pointer (stick). Outputs: bDriveMaterials (material parameters Pointer = (U, V, hover, pressed), PointerHover, PointerVelocity = (x, y, speed, proximity) on Image / Border / shape materials, bIncludeChildren), bDriveShapeGradients (radial gradient center follows the pointer), AnimationPointerValue / AnimationHoverValue (Widget Animation values), MachinePointerInput / MachineHoverInput / MachineProximityInput (state machine inputs). Event On Pointer Effects Updated; Get Pointer State. bPreviewInDesigner + DesignerPointer + bPreviewConditionsAsMet. Widget Animation track "Pointer Effects" (Intensity, TiltAngle, MagnetPull, LightStrength). Value input "Pointer Distance and Motion" (Distance, Proximity, Direction, Speed, VelocityX/Y) on any value track.
