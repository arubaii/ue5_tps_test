# State machines

## What they are
A Widget Animation State Machine (WASM_ asset) picks which animation plays from inputs: Inputs (Bool, Float, Integer, Choice, Vector 2D, Trigger, Press And Hold; built-ins Hovered, Pressed, Focused, Selected, Disabled, Closing; pulses tested with Fired: Clicked, Hover Entered, Hover Exited, Press Started, Released, Focus Gained, Focus Lost, Double Clicked, Right Clicked, and, while the widget has focus, Accept, Back, Gamepad Face Bottom, Gamepad Face Right, Gamepad Face Left, Gamepad Face Top, Gamepad Left Shoulder, Gamepad Right Shoulder, Gamepad Left Trigger, Gamepad Right Trigger, Gamepad D-Pad Up, Gamepad D-Pad Down, Gamepad D-Pad Left, Gamepad D-Pad Right, Gamepad Menu, Gamepad View, Gamepad Left Stick Click, Gamepad Right Stick Click), Layers (Override / Additive, Weight, Animations Affect with Affected Widgets and Channels, Widget Input Targets), States (Plays: Single Animation / Blend 1D / Blend 2D, Playback Once / Loop / Ping Pong / Hold End Pose, Speed Input, Parameters From Inputs, On Enter / On Exit actions) and Transitions (Conditions, Blend Tween / Spring / Cut, Exit Time, priority, random).

Sub-machines: a state with bSubMachine true holds a graph of its own - the nodes (its own Entry, Any State and Exit, and states) whose ParentMachine is that state's Id, all in the same layer's States and Transitions; a transition joins two nodes of the same graph only. Entered, the layer goes in through its Entry; the sub-machine's own transitions can be taken from any state inside it (checked before those inside), and its When Finished waits for the inside to reach its Exit, which holds the pose. Conditions on another layer's state count a layer inside a sub-machine as in it.

Layer widgets: a layer's WidgetInputTargets (Widget Input Targets) name the widgets its built-in inputs are read off - widget paths in the Widget Blueprint, (This Widget), or a machine target name; with several, an input is true when it is on any; empty reads the widget the machine plays on. MaskMode (Animations Affect: All Widgets / Only These / All But These) with MaskTargets (Affected Widgets, the same kinds of names; empty is (This Widget)) limits which widgets the layer poses.

## Playing one
A Widget Animation State Machine Component (UWidgetAnimationStateMachineComponent, Add Component in the designer) plays machines on a widget: its StateMachines entries (Animation Target Widgets - a widget per target, each row listing the animations it is a Track Group of - input overrides, Start On Construct). It plays through the widget's Widget Animation Component when it has one (composed by its Animations With State Machines), or through one of its own. A Widget Animation Component's own StateMachines from before still play. Set inputs from Blueprint (Set State Machine Bool / Number / Trigger...) or drive them from a Flow List or a View Model.

## Building with tools
create_asset {class: WidgetAnimStateMachineAsset} then set_asset with Inputs, Layers[0].States (+ appends) and Layers[0].Transitions; list_options fields FWidgetAnimMachineState / FWidgetAnimMachineTransition / FWidgetAnimMachineCondition for the exact fields. The State Machine editor (double-click the asset) shows the graph and previews it.
