# Polish a widget
> Make an existing Widget Blueprint look finished.
Arguments: blueprint - the Widget Blueprint to polish
Polish {{blueprint}}: describe_widget_blueprint with props, then bring it to the house style - spacing from the scale, consistent corner rounding, text roles (@text / @muted, type scale), one accent color, decorations hit-test invisible, an entrance animation. Change, don't rebuild; list what you changed in a short summary.
