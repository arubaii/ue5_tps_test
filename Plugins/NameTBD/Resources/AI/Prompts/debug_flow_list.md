# Debug a Flow List

Arguments: problem - what is wrong
The Flow List selected in the open Widget Blueprint has a problem: {{problem}}. Call get_context, then describe_widget on the Flow List (its Layout, Effects, Scrolling, Transitions), search_docs for the settings involved, and explain the cause in plain words. Offer the fix as one set_widget call and apply it if the user agrees.
