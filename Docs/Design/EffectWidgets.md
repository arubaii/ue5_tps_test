# Effect widgets: Glass Panel, Drop Shadow, Foldable Dropdown, Flip Card, Advanced Progress Bar

Widgets saved with the earlier `UNameTBD*` classes load as these (`ClassRedirects` in `Config/DefaultNameTBD.ini`: Progress Bar -> Advanced Progress Bar, Glass Blur and Glass Blur Button -> Glass Panel, Flippable Card -> Flip Card, Foldable Dropdown -> Foldable Dropdown): children and same-named properties carry over, the rest takes the defaults. The old Drop Shadow Box has no successor widget (the shadow is a component) and loads as nothing.

## Shared
- **Drawing** (`Widgets/WidgetEffectsDraw.h/.cpp`, namespace `WidgetEffectsDraw`): everything is Slate custom vertices on top of the shapes' geometry (`WidgetShapeGeometry`: `BuildFill`, `BuildStroke`, `CutForGradient`, and the new public `CutAtLevel` - a mesh cut along any linear function so per-vertex colors stay exact), so it draws on every renderer Slate does.
  - Rounded rectangles: `AppendRoundedRect` (per-corner radii, `FitRadii`), `RoundedRectDistance` / `RoundedRectNormal` (signed distance and its gradient).
  - **Soft shadows**: `FSoftBox` + `EvaluateSoftBox` - a rounded rectangle convolved with a Gaussian, exact along x and six samples along y (Evan Wallace's method), so a box smaller than its blur is correctly faint; sigma 0 is the hard box anti-aliased. Meshes: `BuildRings` (rings of the same vertex count round a rounded rectangle at signed distances, edges cut at most MaxSegment apart, optional core fan) + `MakeRingDistances` (dense near the fade). Coverage = the shadow's value per vertex; one draw per layer.
  - **Grain**: `GetGrainBrush` (a 128 x 128 BGRA tile of black or white specks of random alpha, made once with `GenerateDynamicImageResource`), `BuildGrainMesh` tiles it as cells clipped to a convex outline (Sutherland-Hodgman `ClipPolygon`) with 0..1 UVs per cell - custom vertices draw with a clamping sampler, so the tile can't rely on wrap addressing.
  - `PaintMesh` (color per vertex x Coverage x widget tint, optional brush + UVs), `PaintMeshWithPaint` (an `FWidgetShapePaint` over a box: color, gradients, image brush, SVG through `FWidgetSVGBrush` - the image-source rule; a **Material** paint through an optional `FWidgetEffectMaterials` + key + live inputs - without one (Glass, Flip Card, Foldable) it draws as its Color; `bAlongOutline` lays an image or material by each vertex's `Along`).
- **Motion** (`Widgets/WidgetMotion.h/.cpp`): `EWidgetMotion` Smooth / Snappy / Bouncy / Gentle / Linear / Instant (the ready-made buttons' vocabulary) and `FWidgetMotionValue` (tween restarting from where it is; Bouncy is a live spring, `UWidgetAnimSpringLibrary::AdvanceSpring`, bounce 0.3, keeping its velocity). Every widget follows Motion with **Enter Duration** (the way in: open, to the back, rising, hovered) and **Exit Duration** (the way back); 0 = the motion's pace (0.25 / 0.14 / 0.4 / 0.45 / 0.25 s). Animation runs on Slate active timers, registered only while something moves (or a continuous effect is on).

## Glass Panel (`Widgets/Glass/GlassPanel.h/.cpp`; `UGlassPanel`, `SGlassPanel`, `SGlassSurface`)
- A `UContentWidget` (palette NameTBD). Slate: an overlay of the **blur** (`SBackgroundBlur`, Slate's own blur - works wherever Background Blur does; `LowQualityFallbackBrush` = Fallback Color, rounded), the **surface** (`SGlassSurface`, a leaf painting the glass), then the content (padding, alignment). Text is never under the film.
- **Blur Mode**: Uniform (one Background Blur, corners rounded per corner) or **Progressive** (variable blur: one full band up to Fade Start from the Strong Edge, then Fade Steps bands of falling strength `(1 - t)^1.25` to Fade End, nothing after; each band its own Background Blur with only the panel corners it touches rounded - `GetBandRadius`, from the size last painted for a pill). Cost: one blur pass per band.
- **Surface layers** (`SGlassSurface::OnPaint`, each its own layer): Tint (`FWidgetShapePaint`: color, gradient, image, SVG), Grain (Grain alpha, GrainSize px per texel), **Sheen** (white falloff from the lit corner along the light axis, reaching Sheen Reach of the panel; mesh cut where it bends), hover **wash** (Brighten) and press shade (Press Darken), **Inner Glow** (1 - the panel blurred by Inner Glow Size, inside it: an inset shadow in light), **Edge** (inside stroke, per-vertex color by the outward normal against Light Angle: Edge Color + Edge Highlight x facing^Focus + Edge Backlight x (-facing)^Focus - the lit rim and, for thick glass, the far rim). Meshes cached by size, pixel scale, corners and the layout-affecting values; colors per paint.
- **Presets** (`EGlassPreset`, `MakePresetLook`; picking one keeps corners, padding, hover response; editing a Glass value -> Custom): Frosted (default: blur 14, white film 26%->8% diagonal, grain 0.05, lit hairline), Frosted Dark, Clear (blur 3, strong sheen, both rims), Liquid (blur 7, 1.5 px rim with highlight 0.9 and backlight 0.5 at focus 3, inner glow 0.35, wide sheen), Acrylic (blur 32, 72% tint, 3% grain), Smoked, Tinted (blue film, edge and glow), Progressive (Top) / (Bottom) (blur 24 fading from the edge, darkening fading with it, no edge).
- **Hover** (Reaction): Nearest Button (default; polls the nearest `UButton` above at 20 Hz: hovered, focused, pressed, enabled), Own Hover (the panel itself), Blueprint (`SetInteractionState`; what a Glass Button uses), None. Hover Response: Blur Boost, Brighten, Edge Boost, Sheen Boost, Press Darken; Motion + Enter / Exit Duration. Never polled in the designer.
- Blueprint: Make Preset Look, Set Preset, Set Look, Get Look, Set Blur Strength, Set Tint Color, Set Corner Radius, Set Interaction State.

## Drop Shadow (`Widgets/Shadow/DropShadow.h/.cpp`; `UDropShadowComponent`, `SDropShadow`)
- A **UI Component** (`UUIComponent`), added to any widget with the designer's Add Component: `RebuildWidgetWithContent` wraps the widget's own Slate widget in `SDropShadow`, which draws the shadows from the **child's arranged geometry** (its render transform included), so they scale, turn and fade (render opacity) with a Widget Animation; inner shadows are drawn over the widget (a wrapper can't get between its background and content).
- **Layers** (`FDropShadowLayer`): Kind Drop (CSS box-shadow: Offset, Blur as the CSS radius - sigma = Blur / 2 -, Spread, Color), Inner (inset), **Floor** (a pill-shaped oval Floor Width x widget width, Floor Height tall, Offset.Y below the bottom edge; it stays on the floor while the widget lifts, wider, softer and 1/sqrt(elevation) fainter). Drawn in order, each its own layer.
- **Presets** (`MakePresetLayers`, in Shadow Color; picking one or changing Shadow Color rewrites the layers, editing a layer -> Custom): Subtle, Soft (default), Elevated, **Sleek Layered** (six shadows 1, 2, 4 ... 32 px at 7.5% - the long natural tail), Long & Dramatic, Hard Offset (blur 0), Glow, Colored Shadow (Glow and Colored start in the accent blue when the color is black), **Floating** (detached floor oval), **Contact (Floor)** (tight dark oval where it touches), Soft UI Raised / Pressed (white up-left + dark down-right, outer / inner), Inner Shadow.
- **Mesh**: under an opaque widget the rings follow the shadow's own shape (few rings, dense in the fade, core fan); **Under Widget** Hide (Auto: Glass Panels, Background Blurs, Glass Buttons) builds rings round the widget from its edge outward instead, so the clear part under see-through glass is crisp. Cached per layer by everything it depends on.
- **Corners**: Match Widget (`ReadCaster`: Glass Panel, Rectangle (rounding / individual / fully rounded), Ellipse (pill), a Glass Button's glass, a ready-made button's Rectangle background, a Button's Normal brush, Border Background / Image Brush (rounded box brushes, by reflection), Background Blur Corner Radius) - read every paint, so a corner animated by a Shape Target is followed; or Custom.
- **Elevation** scales every Drop / Floor layer's offset, blur and spread; **React To Hover** raises it to Hover Elevation (and Pressed Elevation while the owner Button is pressed) and lifts the widget by Hover Lift (its arrangement moves, not its slot); polled per frame only between mouse enter / leave or while focused. Blueprint: Set Preset, Set Shadow Color, Set Layers, Set Opacity, Set Elevation (animated), Set Forced Hover / Clear Forced Hover, Make Preset Layers.

## Foldable Dropdown (`Widgets/Foldable/FoldableDropdown.h/.cpp`; `UFoldableDropdown`, `SFoldableDropdown`, `SFoldableHeader`, `SFoldableBody`)
- `UWidget` + `INamedSlotInterface`: slots **Header** and **Body** (properties `HeaderContent` / `BodyContent`). Slate: an `SPanel` whose desired height is header + body x open amount, so the layout below glides with it; the body (`SFoldableBody`, ClipToBoundsAlways) is arranged at that height and lays its content out at full height inside, offset / scaled by the animation; fully closed it is Collapsed (no layout, paint or hit test).
- **Animation**: Fade & Slide (default; drifts Slide Distance down while fading, the fade a little behind the height), Reveal (uncovered like a blind), Slide (comes down out from under the header), Fade, Pop (scales from 94% and fades). Motion + Enter (open) / Exit (close) Duration; Bouncy overshoots the height.
- **Header** (`SFoldableHeader`): its own input - click (captured; fires on release over it; a double click toggles again), Enter / Space / gamepad accept when focused (Focusable); hover and press tint the header's rounded background (Header Color / Hover / Pressed, Corner Radius; eased). Content gets the full width less the marker, centered down the header.
- **Icon** (vector, anti-aliased, round caps and joins): Chevron (down -> up), Side Chevron (right -> down), Plus / Minus (the upright turns and folds into the bar), Caret (filled), Image (Image Source Texture 2D / SVG, turned by Icon Open Angle), None; left or right, size, line width, spacing, color.
- Divider (fades in with the body), Body Padding. Accordion Group: opening one closes the others with the same group in the same panel. In the designer, Expanded shows it open, and selecting a widget inside the body opens it (`OnDescendantSelectedByDesigner`). Events: On Expansion Changed (start), On Fold Finished (end).

## Flip Card (`Widgets/FlipCard/FlipCard.h/.cpp`; `UFlipCard`, `SFlipCard`)
- `UWidget` + `INamedSlotInterface`: slots **Front** and **Back** (properties `FrontContent` / `BackContent`). Each face is an **`SShapeBox`** - a real perspective turn (its Angle + Perspective, drawn offscreen and mapped back for input only while turned; at rest it draws as it is, no cost). `ShapeBox.cpp` `MaxAngleDegrees` is 89.5 (was 80) so a face can turn all but edge-on; the Shape Box Details still stop Angle at 80.
- The turn is a value in half turns (back odd, front even); the face looking toward the viewer is shown at what is left of it (`ApplyPose`). Reverse On Return turns back the way it came; off carries on round.
- **Motions** (each a different movement): Flip (sideways, cubic in-out), Flip Vertical, Spring Flip (Bouncy: swings past and settles), Lift & Flip (scale + Lift and up 8 px at the top of the turn, shadow spreading), Swing (front hinged on its left edge opening away, back hinged on its right closing in - the hinge kept in place by `FShapeBoxShape::Evaluate`), Coin Spin (1.5 turns, ease-out, 1.6x the duration), Fade Through (out to 92% and transparent, then the back in), Shuffle (front slides out right and tucks under; z-order swaps halfway).
- On every turned face: **Shading** (black, 1 - cos of its angle) and **Glare** (a white wash rising toward the near edge, |sin| of the turn), drawn on the face's outline (Corner Radius) built flat, colored there, then projected through the same Shape Box shape. **Shadow** under each shown face: its projected bounds as a soft box, offset and blur growing with lift.
- **Tilt On Hover**: Max Tilt degrees toward the pointer (the part under it pressed away), eased, with a radial highlight (Tilt Glare) at the pointer. Trigger: Click (default; the card is Visible, face buttons take their own clicks), Hover (back while hovered), Blueprint only. Events: On Flip Started, On Flip Finished.

## Advanced Progress Bar (`Widgets/Progress/AdvancedProgressBar.h/.cpp`; `UAdvancedProgressBar`, `SAdvancedProgressBar`, `FAdvancedProgressBarStyle`)
- `UWidget` (palette NameTBD); Percent (Set Percent animates, Snap To Percent doesn't, bindable through `PercentDelegate`), Indeterminate, Motion + Enter (rise) / Exit (fall) Duration, Bar Style.
- **Bar**: Direction (four ways or From Center), Bar Size (length x thickness; vertical turned), Fully Rounded / Corner Radius, **Fill End** Rounded (its own rounded bar; shorter than its rounding, a full round end clipped to the track's - it grows out of the track's end) or Flat (the track cut straight), Fill Inset, Track paint + outline. **Ring**: diameter, thickness, Start Angle, Sweep (gauges), direction, Round / Flat caps (strokes of the shape geometry, so anti-aliased with real caps).
- **Curve** (`EProgressBarShape::Curve`, appended): fills along a line of your own. **Curve Source** (`EProgressCurveSource`): Ready-Made Curve (Curve Template, default Swoosh), Curve Preset (a `UWidgetCurvePresetAsset`) - both through a transient `UCurveShape` the UMG widget makes (`MadeCurve`, never in a tree; Catmull-Rom for ready-made lines) - or Curve Widget (a Curve in the same Widget Blueprint, `GetOptions = GetWidgetOptions` through `WidgetTreeLookup`; falls back to the ready-made line while none is picked). `SAdvancedProgressBar::SetCurve` takes the `UCurveShape`; `PaintCurve` builds its line with `UCurveShape::BuildCurvePath` at the bar's box less half the thickness each side (Curve Size, default 240 x 80), flattened, reversed with Reverse Curve, closed lines measured back to their start, resampled every 4 units; rebuilt when the Curve's mesh hash or the size changes. Curve Thickness, Curve Cap Round / Flat, **Curve Cap Angle** (flat ends slanted at every end - track, segments, fill's leading edge - by `WidgetShapeGeometry::SlantStrokeEnd`; chevron segments). Everything else as the ring: segments with a gap (round caps add their width), whole segments, trail, gradient span (colors per vertex by `Along.X` = fraction along the line), glow lanes along the line's normals, shine, markers (ticks across the line), indeterminate (a sliding segment on an open line, a breathing span going round a closed one). A full track round a closed line is one closed stroke (no caps meeting at the start).
- **Material paint** on Fill and Track (all three shapes): the bar's own instances (`FWidgetEffectMaterials`, key 0 track / 1 fill), handed **Progress** (the value shown), **Trail** and **ShapeSize**; on a Curve laid along the line (U 0..1 from the first point - Image Tile Length isn't used there). Its parameters are listed from the material in the editor (`PostEditChangeProperty`, also on the Widget Blueprint's own widget).
- **Segments** (bar pieces or ring arcs with a pixel gap - round caps get their width added to the gap), Whole Segments (lights only full ones).
- **Fill paint** (`FWidgetShapePaint`) with **Gradient Span** Along Track (revealed as it fills; round a ring), Along Fill (whole gradient in the filled part), Over Box (the paint's own angle); meshes cut at the stops (`CutAtLevel`) so gradients are exact; ring colors per vertex from where each vertex is along the arc (the stroke's `Along`). Color By Value + Value Colors (red -> amber -> green by default).
- **Trail**: a loss drops the fill and holds the lost part in Loss Color for Trail Delay, then drains over Trail Duration; a gain shows at once in Gain Color and the fill follows after the delay.
- **Effects**: Glow (a soft box round the bar's fill / four lanes along the ring's, in the leading color), Shine (a band sweeping along the fill every Shine Interval, 0.9 s per sweep), Stripes (bars: 45-degree stripes clipped to each fill piece, moving at Stripe Speed), Markers (ticks across the track). Indeterminate: a segment whose head runs ahead of its tail sliding through (bar, gauge) or a breathing arc going round (full ring).
- Events: On Percent Changed, On Filled, On Emptied (when the fill arrives).

## Production expectations
"There could be more use cases that users desire that I haven't thought of, but would be expected in a production-grade application."
- **Beyond the request (Curve shape):** three sources for the line, one of them a live Curve widget edited with the canvas tools; slanted flat ends on every piece (chevrons, sci-fi gauges); every bar feature on the curve (segments, trail, gradients along it, glow, shine, markers, indeterminate, closed loops); Reverse Curve; Material paint on every bar shape with Progress / Trail handed to it.

## Decisions made without asking
- One shared motion vocabulary (`EWidgetMotion`, a new enum) rather than reusing `EStyledButtonMotion` (in the buttons' header) or Gemini's easing enum.
- Drop shadow is a UI Component (the engine's widget-component system, as the Widget Animation Component), not a wrapper widget or runtime reparenting.
- Glass blur stays on Slate's Background Blur (the request: the same graphics APIs as the native blur); "beyond Gaussian" comes from progressive bands and the vector surface layers, not a custom render pass.
- Flip Card turns through Shape Box rather than its own offscreen renderer.
- The old blur button loads as a Glass Panel (keeps its child) rather than a Glass Button (a Button's slot class differs from what was saved).

## Still open
- Glass refraction / lensing (a liquid-glass edge that bends what is behind) needs the backdrop in a material (Slate post buffers, 5.4+) - not done.
- A Glass Panel on a Diegetic Screen: its blur is an `SBackgroundBlur`, not a `UBackgroundBlur`, so the screen's glass material doesn't take it over (Background Blur in the world renders opaque - DiegeticUI.md).
- Curve bar: stripes; a Curve Widget's later runtime edits (Set Points from Blueprint) reach the bar on its next repaint, not at once; Image Tile Length along the curve; Fill Inset only narrows the fill.
- Ring stripes; Drop Shadow on non-rectangular shapes (stars, triangles cast their box); a Drop Shadow Box widget for Slate-only use.

## Unverified (no engine here: written, not compiled or run)

- `SBackgroundBlur`'s `CornerRadius` taking an attribute (`TAttribute<FVector4>::CreateSP`), `SetApplyAlphaToBlur`, many bands stacked in one panel, and the low-quality fallback.
- The progressive bands' seams at 8 steps; the grain's look at Grain Size 1 on high-DPI.
- Soft-shadow ring meshes at big offsets with Under Widget hidden (rings capped at 48), and Wallace's approximation on per-corner radii.
- `FGeometry::ToPaintGeometry` with a render transform + pivot (the dropdown's turned image icon), `FGeometry::MakeChild` with a render transform (Pop), `SPanel` + `TSlotlessChildren` panels.
- Shape Box at 89.5 degrees (warped mesh, hit cells) and Swing's hinge correction; flipping a card whose faces hold focusable buttons.
- Curve bar: `GetOptions` on a member of a struct property (`FAdvancedProgressBarStyle::CurveWidget`) finding the widget's `GetWidgetOptions`; a transient `UCurveShape` made with `NewObject` outside any tree; slanted ends on short segments; the designer repainting the bar while the Curve it follows is edited.
- `BIND_UOBJECT_DELEGATE` with the new Slate delegate types; `UContextMenuButton::OnVisualStateChanged` firing from the designer toolbar's state preview.
