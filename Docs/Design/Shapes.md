# Shapes

## Shapes: outline materials and the Rectangle (Buttons v1)
- **Outline materials:** `FWidgetShapePaint` has **Image Mapping** (`EWidgetShapeImageMapping`: Stretch Over Shape / **Along Outline**) and **Image Tile Length**, shown only for an Image paint. Along Outline (strokes only; hidden on the Fill by `FWidgetShapeDetails`): U runs along the outline (0..1 once round each contour, or one per Tile Length px), V across the stroke (0 inside edge, 1 outside). Dashes and Trim Path keep their place on it.
  - Geometry: `FWidgetShapeMeshVertex` carries `Along` (distance, across) and `OutlineLength`; `FStrokeBuilder` fills them (sections carry `Along`; `AcrossAt`; round caps; a closed run ends on a copy of its first section one outline further, so U never runs back across the last edge). `TrimRun` / `DashRun` report where each piece starts. `CutAlong` lerps them. `FWidgetShapePaint::GetOutlineUV` maps them; used by `SWidgetShape::PaintMesh` (stroke only) and `SFlowListScrollBar::PaintMesh` (scroll bar lines too).
  - Blueprint: `SetStrokeMaterial`, `SetFillMaterial`, `GetDynamicStrokeMaterial`, `GetDynamicFillMaterial`. `GetImagePaint()` = the stroke's paint when it is drawn with an image, else the fill's (what a Design Target's texture/material channels act on).
  - `UShapeWidget::SetExternalPainter`: another Slate widget repainted by `InvalidateShape` (the Context Menu Button's Background Shape).
- **SVG paint:** an Image paint has **Image Source** (`EWidgetImageSource`, default Texture 2D: the Image brush, as before) and **SVG** (shown for Image Source SVG; the brush is then hidden and ignored). `DrawsSVG()` / `DrawsBrush()`. `SWidgetShape::PaintMesh` takes the paint's `FWidgetSVGBrush` (`FillSVG` / `StrokeSVG`) and draws the SVG at the size of the shape's box on screen (`Frame.Size` through the render transform), stretched over the box or laid Along Outline like a texture, tinted by the paint's Color; the mesh isn't painted until the first drawing is ready. Design Target texture / material channels and `SetFill/StrokeMaterial` set Image Source back to Texture 2D. See SVG.md.
- **Rectangle** (`URectangleShape`, `ShapeWidgets.h`): Corner Rounding (px, held to what fits), **Fully Rounded** (pill), Individual Corners + Corner Radii (X TL, Y TR, Z BR, W BL). Shape value Corner Rounding. "Pill" added to a Custom Shape's Start From.

## Shape Box corners
- **Chamfer with one leg:** a Chamfer corner's leg left at 0 (or below) follows the other (`ShapeBoxPrivate::GetChamferLegs`), so X alone cuts a 45-degree corner X along each edge; it used to need both legs above 0, and X did nothing until Y was set (on a Context Menu Button's shape and every other Shape Box alike). Bevel is unchanged (X alone leans a side). Tooltips and the Key Values description say so.

## Shapes hold a child (Shapes v1)
- **What:** every shape (`UShapeWidget`: Ellipse, Rectangle, Triangle, Star, N-gon, Custom Shape) is a **`UContentWidget`** now and holds one widget drawn over it, as a Border does - a star button's label, a badge's count, an icon in a circle; no Overlay needed. The split stays: **shapes = vector background with content on top; Shape Box = bending/warping the content itself.**
- **Slate:** `SWidgetShape : SCompoundWidget` (was `SLeafWidget`): paints the fill/stroke meshes exactly as before (layers LayerId, LayerId+1), then the hit cells (below), then the child via `SCompoundWidget::OnPaint` at `MaxLayer + 1`. `OnArrangeChildren` places the child in the **Content Area** (`GetContentArea`), then the slot's padding and alignment (`AlignAxis`, mirrored right-to-left). `ComputeDesiredSize`: `DesiredSize` when there is no child (or it is Collapsed), or Size To Content is off - so a shape without a child reports exactly what it did; else `ComputeSizeForContent`. Both the area and the size are cached by hash (mesh hash + size + content aspect). Arg **`PaintOnly`** (the Context Menu Button's Background Shape painter, `SContextMenuSlateButton::SetBackgroundShape`): no content, no hit cells, Desired Size. **`SetUnfilledBrush`**: while the shape's Fill is off, its inside is painted with that brush instead (Image paint over the shape's box when it has a resource, its tint as a Color paint otherwise); the fill mesh is then built (hash includes it) and cut for the paint actually used - the Context Menu Button's own brush inside an unfilled Shape Style.
- **Slot:** `UShapeWidgetSlot : UPanelSlot` ("Shape Slot"): **Padding**, **Horizontal / Vertical Alignment** (default **Center / Center**, padding 0), setters; `BuildSlot(SWidgetShape)` pushes content + layout (UBorderSlot pattern). `UShapeWidget::GetSlotClass / OnSlotAdded / OnSlotRemoved / RebuildWidget` build it (a plain `UPanelSlot` still works, without layout).
- **New settings on the shape** (category **Content**):
  - **Content Area** (`EWidgetShapeContentArea`): **Bounds** (the box, as a Border), **Inside Stroke** (the box less the stroke's inner width - `GetInnerStrokeWidth`: all of it Inside, half Center, none Outside), **Inscribed** (default: the largest rectangle inside the outline and its stroke, at the content's aspect - padding included; the widget's aspect when the child asks for nothing). Follows Fit, Shape Scale and Shape Rotation (it is computed on the outline built through `MakeFrame`).
  - **Size To Content** (`bSizeToContent`, default on): with a child, the shape asks for the size that gives the child its desired size in the Content Area (Bounds: content; Inside Stroke: + 2 x inner stroke; Inscribed: up to 6 passes of "grow evenly by what is missing" - an Inscribed circle round text ends ~1.41x the text). Grows evenly, so the shape takes the content's proportions.
  - **Hit Test Outline** (`bHitTestOutline`, default off): only the outline's inside is hovered/clicked. At runtime only (never in the designer): the UMG widget routes its visibility through the Slate shape (`SyncShapeVisibility` -> `SWidgetShape::SetRequestedVisibility`, the Shape Box pattern) - Visible becomes **Self Hit Test Invisible** and the fill is tiled with invisible `SWidgetShapeHitCell`s (leaf widgets painted with the shape as paint parent, so the bubble path is cell -> shape -> its parents), built with the mesh from `WidgetShapeGeometry::BuildFillRects` (rows >= 2 units, <= 96 rows, rows with the same span merged: a rectangle is 1 cell, a circle ~45). Cells are painted before the child, so a button inside is hit first. While routed, a Blueprint binding on Visibility is replaced by the property's value (as on Shape Box) - only when Hit Test Outline is on.
  - Blueprint: `SetContentArea`, `SetSizeToContent`, `SetHitTestOutline`, `GetContentAreaRect` (the area as last arranged).
- **Geometry** (`WidgetShapeGeometry`): **`FindInscribedRect(Outline, Aspect, Margin, OutRect)`** - grows rectangles of one aspect about candidate centers (box middle, area centroid, a 3x3 grid) by bisection until an edge touches them (`SegmentTouchesBox`, Liang-Barsky), keeps the best, then hill-climbs 8 ways with halving steps. A rectangle no edge touches with its middle on the fill is wholly inside, so holes (a ring) are kept out. Checked outside the engine: circle d100 -> 70.71 square (exact), triangle -> the optimal 50 square at the base, ring -> fits in the band. **`BuildFillRects`** as above. **`CutAtLevel(Mesh, Level, ValueOf)`**: the cut `CutForGradient` makes at a stop, along any linear function of position - the effect widgets' exact progress gradients and moving bands (EffectWidgets.md).
- **Kept out of Looks, Shape tracks, Flow List item looks and presets:** `UShapeWidget::IsContentProperty` (Content Area, Size To Content, Hit Test Outline), skipped by `WidgetShapeAnimation::GetProperties` and `WidgetShapePresets::GetPresetProperties`, as Desired Size is. `Slots` (UPanelWidget's) is never gathered: those filters keep only properties owned by `UShapeWidget` subclasses. So existing Look / Shape key bags keep their layout.
- `UShapeWidget` now has an `FObjectInitializer` constructor (default argument), as `UContentWidget` requires. `InvalidateShape` invalidates Layout (not just Paint) when the shape sizes to a child.
- **Not done (follow-up):** **Clip To Shape** (mask the child to the outline). Slate clips only to rectangles/quads, so it needs an offscreen render like Shape Box's warped path (virtual window, render target, input mapped back) - opt-in, cost only when on. Deferred rather than half-built.


## Curve (`Widgets/Shapes/CurveShape.h/.cpp`)
- **What:** `UCurveShape` ("Curve", palette NameTBD) - a line of your own: a swoosh under a heading, an arrow pointing at a button, a divider, a wave, a tutorial path, a sparkline, a signature drawn live. A **`UCustomShape` subclass**, so the canvas path editor (Edit Shape, Pen, drag, double-click to add, Delete), the shape Preset row (`.wshape` files), Start From, Fit / Flip, Trim Path, dashes, gradients, Along Outline materials, Looks and Shape tracks all work on it unchanged. Defaults for a line: Fill off, Stroke on (4 px, Round cap and join, white), Desired Size 200 x 80, Content Area Bounds, Self Hit Test Invisible, the Wave template.
- **Smoothing** (`EWidgetCurveSmoothing`, default **Smooth Through Points**): `BuildPath` works the handles out per contour (`SmoothContour`): each inner point's handles lie along the line between its neighbours, a third of the way to each (x **Smoothness**, 0..2, default 1); an open line's ends aim at their neighbour's handle tip; a **Disconnected** point is a sharp corner (made Straight, Corner Radius kept). **Handles As Drawn** = the Custom Shape's own handles; **Straight Lines** = every vertex Straight. Switching to Handles from Smooth with no handles stored bakes the worked-out handles into Path (`PostEditChangeProperty`), so the curve keeps its shape. The canvas editor hides handles while the curve works them out (`UCustomShape::UsesVertexHandles`, false unless Handles; `SWidgetShapePathCanvas::ShowsHandles`) and draws curve points as circles, Disconnected ones as squares.
- **Stroke hook (every shape):** `UShapeWidget::BuildStrokeMesh` (virtual; default `WidgetShapeGeometry::BuildStroke` with Stroke and Trim - what `SWidgetShape::Rebuild` called before) and `PaintsStrokeGradientAlongOutline` (virtual, default false). The Curve's override, only when it has markers, a varying width or a gradient along it (else the default): per open line, the drawn part as Trim Path measures it (same Offset wrap as `TrimRun`), the line stopped short of an arrowhead's tip (`WidgetPathGeometry::GetMarkerInset`), built with `BuildStroke` per piece (dash offset + piece start, so dashes stay put while it draws on; Along X shifted, OutlineLength the whole line) or, with a varying width, `WidgetPathGeometry::BuildDashedRibbons` (flat ends - caps aren't drawn on a tapered line). Closed lines are stroked as before. Lines are resampled every 4 units when width or colour vary along them.
- **Ends:** Start / End Marker (`EWidgetPathMarker`, the Widget Path markers: Arrow, Open Arrow, Dot, Diamond, Bar), Marker Size (px, default 12); built by `WidgetPathGeometry::BuildEndMarker` at the drawn part's ends, turned along the stretch of line they cover (tip minus the point Marker Size back), painted with the stroke. They ride the ends of Trim Path.
- **Width:** Start / End Width Scale (taper, 0 to a point), Use Width Curve + Width Curve (`FRuntimeFloatCurve`, X 0..1 along, Y multiplier) - as the Widget Path look's.
- **Gradient Along Curve** (default on): a Linear / Radial stroke gradient is coloured per vertex by `Along.X / OutlineLength` (`SWidgetShape::PaintMesh`; the stroke mesh isn't cut for the gradient then).
- **Shared from Widget Paths:** `WidgetPathGeometry::GetMarkerInset`, `BuildEndMarker`, `BuildDashedRibbons` (declared in `WidgetPathTypes.h`, defined in `WidgetPathLayer.cpp` over the layer's private builders, unchanged).
- **Templates** (`EWidgetCurveTemplate`, `UCurveShape::MakeTemplatePath`): Line, Arc, S-Curve, Wave, Zigzag, Spiral, Loop, Heartbeat, Swoosh, Bounce (smooth arcs, Disconnected at the ground), Steps, Infinity (closed). The Details' Start From lists them first for a Curve ("Curves"), setting Path and Smoothing in one undo step; Blueprint Set Curve From Template.
- **Curve Presets** (`UWidgetCurvePresetAsset`, Data Asset "Curve Preset"): Path, Smoothing, Smoothness, **Apply Look** + Stroke, Fill, markers, widths, Width Curve, Gradient Along Curve. The Curve's **Curve Preset** applies one when picked (`ApplyCurvePreset`) and **follows** it: `PresetAppliedHash` (hash of the exported text of what the preset covers, taken when applied); `PostLoad` takes the preset again when that hash still matches (the asset's later edits reach it), else lets it go; an edit in the Details of anything the preset covers lets it go (`PostEditChangeProperty`); Blueprint Set Points / Add Point / Plot Values / Clear Points / Set Curve From Template let it go too. **Save Preset** (a chip on the Outline row, `SaveAsCurvePreset`, through `WidgetEditorHooks::CreateAsset`) makes one and follows it. `SyncPresetToTemplate` writes what a preset (or the bake to Handles) set onto the Widget Blueprint's own widget, as `UWidgetPathLayer::SyncLookToTemplate` does. Curve Preset is kept out of Looks, Shape tracks and `.wshape` presets (`UShapeWidget::IsContentProperty`).
- **Blueprint:** Apply Curve Preset, Copy To Curve Preset (runtime too), Set Curve From Template, Set Points (box fractions, closed or not), Get Points, Add Point (Min Spacing in Slate units at the last laid-out size), Add Point At Local Position, Clear Points, Plot Values (evenly spaced, Min / Max or auto range; a flat line sits mid-height), Get Curve Length, Get Point At Fraction / At Distance (widget-local position and heading in degrees, clockwise from right - a Render Transform Angle; wraps on a closed curve), Find Fraction Nearest. Sampling reads the first line as last painted.

### Curve: production expectations
"There could be more use cases that users desire that I haven't thought of, but would be expected in a production-grade application."
- **Beyond the request:** smoothing through points (place points, no handles - Illustrator's Curvature tool, Figma's auto-smooth) with sharp corners kept; arrowheads and other end marks that ride a draw-on; taper and width curves; a gradient along the line; twelve ready-made curves; presets as assets that follow later edits (not only copies), and the existing per-kind `.wshape` presets; drawing from data (Set Points, Add Point - signatures, trails; Plot Values - sparklines); sampling (point and heading at a fraction or distance, nearest fraction) for moving icons along a curve; a curve doesn't block the pointer by default.
- **Still open:** caps on a tapered line (ribbons end flat); markers and taper on closed contours; width varying with dashes keeps each dash's own flat ends only; a Curve Preset edited while a Widget Blueprint using it is open reaches it on its next load, not live; markers drawn with an image or material (the Widget Path's Start / End Marker Image) - they take the stroke's paint; a glow under the line (use a Drop Shadow component's Glow); Curve values in the Shape track's value list (Smoothness, taper) - they animate through Looks / Shape key bags instead; Constraints' Follow Path reading a Curve directly (it takes a Widget Path's route).
